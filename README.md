# 나만의 프롬프트 관리 프로그램

파편화된 AI 프롬프트를 체계적으로 관리하기 위한 파이썬 콘솔 프로그램입니다.
제목/내용/카테고리/즐겨찾기 여부로 프롬프트를 저장하고, 목록 조회·카테고리별 조회·검색·즐겨찾기 기능을 제공합니다.

## 실행 방법

1. Python 3.10 이상이 설치되어 있어야 합니다.
2. 저장소를 클론하거나 다운로드합니다.
3. 프로젝트 폴더로 이동한 뒤 아래 명령어로 실행합니다.

```bash
python3 main.py
```

4. 메뉴에 표시되는 번호를 입력해 원하는 기능을 선택합니다.

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 새 프롬프트를 등록합니다 |
| 2 | 프롬프트 목록 | 등록된 모든 프롬프트를 번호와 함께 출력합니다 |
| 3 | 카테고리별 조회 | 선택한 카테고리에 속한 프롬프트만 출력합니다 |
| 4 | 프롬프트 검색 | 키워드로 제목/내용을 검색합니다 |
| 5 | 프롬프트 상세 보기 | 특정 프롬프트의 전체 내용을 확인합니다 |
| 6 | 즐겨찾기 관리 | 프롬프트를 즐겨찾기에 추가하거나 해제합니다 |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아서 확인합니다 |
| 8 | 조회수 Top 목록 (보너스) | 프롬프트를 조회수 순으로 정렬해 보여줍니다 |
| 0 | 종료 | 프로그램을 종료합니다 |

## 프롬프트 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

카테고리는 미리 정의된 6가지 중 선택하거나, 직접 새로운 이름을 입력할 수 있습니다.

## 참고 사항

- 추가한 프롬프트와 즐겨찾기 상태는 프로그램 실행 중에만 유지되며, 종료 시 초기화됩니다.
- 기본 프롬프트 3개는 이전 Codyssey 미션(B1-1 LLM 워크플로우 자동화, B1-3 노코드 자동화)에서 실제로 작성한 프롬프트를 사용했습니다.
